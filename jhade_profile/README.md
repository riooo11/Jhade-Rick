# Programmer Profile — Next.js

A simple frontend-only programmer profile made with Next.js and CSS.

## Run it

1. Install Node.js.
2. Open this folder in VS Code.
3. Run:
   `npm install`
4. Then:
   `npm run dev`
5. Open the local address shown by Next.js.

## Customize

Edit `app/page.js` to change your name, education, projects, email, and profile text.
Edit `app/globals.css` to change the design.
